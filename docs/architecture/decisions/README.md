# Decisões de Arquitetura (Architecture Decision Records - ADR)

Este diretório armazena todos os registros formais de decisões arquiteturais do projeto.

## Padrão de Nomenclatura
`ADR-XXX-<titulo-curto>.md` (exemplo: `ADR-001-stack-tecnologica-mvp.md`)

## Template Básico
- **Número e Título**
- **Status:** Proposto | Aprovado | Rejeitado | Substituído
- **Data e Autores**
- **Contexto:** Qual é o problema ou necessidade técnica?
- **Alternativas Consideradas:** Quais opções foram avaliadas?
- **Decisão:** Qual opção foi escolhida e por quê?
- **Consequências:** Quais são os impactos positivos e negativos/trade-offs?
